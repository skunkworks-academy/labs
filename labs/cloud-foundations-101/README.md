# LAB-CLD-101 - Cloud Foundations and Shared Responsibility

A 60-minute, browser-only workbook that turns cloud service selection and shared responsibility into a practical architecture decision.

## What learners practise

- Distinguishing IaaS, PaaS and SaaS by the operating control a workload genuinely needs.
- Mapping provider and customer responsibilities without assuming that "managed" means "someone else owns it".
- Treating identity, data classification, monitoring, recovery and cost ownership as launch requirements.
- Explaining why a real cloud change needs authority, current guidance and a governed recovery plan.

## Delivery and safety

- Level: Beginner
- Duration: 60 minutes
- Environment: Any modern browser
- Evidence: Browser-local progress and a printable personal completion record
- Network: No cloud account, tenant, deployment, billing operation or external credential is used.

All organisations, workloads, data and cost examples are fictional training material. The completion record is not an accredited certificate, deployment approval or verified assessment.

## Files

- `index.html` - learner-facing interactive workbook
- `manifest.yaml` - delivery, learning and safety metadata
- `instructor-guide.md` - facilitation, answer and reference guidance

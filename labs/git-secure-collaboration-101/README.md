# LAB-DEV-101 - Git, GitHub and Secure Collaboration

A 60-minute, browser-only workbook that teaches the delivery practices behind reviewable, protected and secret-safe software changes.

## What learners practise

- Separating branches, commits, pull requests, reviews and merges by their control objective.
- Preparing a focused pull request with intent, scope, validation, risk and rollback evidence.
- Applying protected-default-branch and ruleset reasoning to a team repository.
- Recognising that secrets belong in approved secret-management systems, not source control, chat or documentation.

## Delivery and safety

- Level: Beginner to Intermediate
- Duration: 60 minutes
- Environment: Any modern browser
- Evidence: Browser-local progress and a printable personal completion record
- Network: No GitHub account, Git command, repository clone, pull request, token or code push is used.

All repositories, branch names and change scenarios are fictional. The completion record is not a GitHub credential, repository permission or verified code-review result.

## Files

- `index.html` - learner-facing interactive workbook
- `manifest.yaml` - delivery, learning and safety metadata
- `instructor-guide.md` - facilitation, answer and reference guidance

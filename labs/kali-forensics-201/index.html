Lab summary

Treat every artefact as evidence before it becomes a data source.

  • 01
    Choose a workflow that reduces unintended writes and records the evidence-handling boundary.
  • 02
    Use hash, partition and file-list observations to build a repeatable disk-image triage note.

  • 04

!

Forensics is not permission to access systems

This lab does not perform live scanning, interception, acquisition or account access. Use it only to learn evidence-preserving reasoning with synthetic fixtures. Real-world forensic work needs documented legal authority, validated procedures, appropriate write protection and an organisation-approved chain of custody.

Module 1

Preserve evidence before you explore it.

Kali Linux Live includes a forensic mode intended to avoid touching internal disks or automatically mounting removable media. That feature is useful, but practitioners must still validate their tools and procedures for the specific evidence, legal setting and engagement.

Authority

Know who owns the evidence.

Record case scope, source, operator and approved purpose before examining a real artefact.

Integrity

Hash before and after.

Capture the acquisition or supplied-fixture identity and record the tool/result used.

Read only

Prevent unintended writes.

Use a validated workflow that does not auto-mount or alter evidence media.

Module 3

Filter an offline network capture.

A stored PCAP is evidence, not a licence to probe the systems named in it. Preserve the capture identity, the query used and the resulting rows so another analyst can reproduce your observation.

Simulated offline PCAP output

Document your filter and its limits.

No live capture
analyst@kali:~/case-k201$ tshark -r case-traffic.pcapng -Y 'dns || http.request'
09:42:12  10.10.20.15 → 10.10.20.53  DNS  Standard query A telemetry.training.invalid
09:42:13  10.10.20.15 → 198.51.100.21 HTTP GET /checkin
analyst@kali:~/case-k201$ sha256sum case-traffic.pcapng
218748df0f8cc0793c49cf47bcf537472f6e0d6871f28f6aef91611ff7b1c526  case-traffic.pcapng
# .invalid and 198.51.100.0/24 are documentation-only values in this synthetic exercise.

Stay offline

  • Read the capture; do not contact the shown host.
  • Record the filter verbatim.
  • Correlate event time, host and process context where authorised.

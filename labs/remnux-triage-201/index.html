Module 1

Start with an analysis boundary.

REMnux is a Linux toolkit for malware analysis and reverse engineering. The toolset helps an analyst work consistently; it does not remove the need for lawful authority, isolation, evidence handling or review.

Authority

Know the case scope.

Use only supplied training fixtures or evidence covered by a documented authorisation.

Isolation

Default deny networking.

Do not use bridged networking or a host workstation as an analysis target.

Recovery

Return to known good.

Record the fixture version and use an approved snapshot or disposable workspace.

Module 3

Correlate memory artefacts; do not jump to a verdict.

Memory-forensics outputs become valuable when they are related to the same timeline, process ancestry and case context. This example uses an entirely fabricated memory image summary.

Ask before concluding

  • Which parent process created the child?
  • Which module, command line and timeline records corroborate it?
  • Does the case design explain the test-network address?

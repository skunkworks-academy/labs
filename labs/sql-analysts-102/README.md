# LAB-DAT-102 - SQL for Analysts

A 60-minute browser-only workbook that teaches the reasoning behind safe, explainable SQL analysis: the question, fields, filters, joins, aggregates and interpretation.

## What learners practise

- Turning a plain-language business question into a minimal selection and filter design.
- Identifying a documented relationship/key before joining tables.
- Using aggregate and grouping logic to create a reproducible result.
- Explaining the limits of a result and protecting data through minimisation and approved access.

## Delivery and safety

- Level: Beginner to Intermediate
- Duration: 60 minutes
- Environment: Any modern browser
- Evidence: Browser-local progress and a printable personal completion record
- Network: No SQL runner, database connection, personal data, credential or query submission is used.

All names, tables, IDs and results are synthetic training material. The completion record is not an accredited certificate, database credential or approved data-access record.

## Files

- `index.html` - learner-facing interactive workbook
- `manifest.yaml` - delivery, learning and safety metadata
- `instructor-guide.md` - facilitation, answer and reference guidance

## Local preview

From the repository root, run:

    python3 -m http.server 8080

Then open `http://localhost:8080/labs/sql-analysts-102/`.

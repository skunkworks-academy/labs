## Safe delivery model

The security tool labs use a private fictional range, resettable targets, offline wireless evidence and synthetic reports. The API labs use local fixtures. Active testing is permitted only against systems explicitly included in a written authorisation and rules-of-engagement document.

## Existing practical labs

The Docusaurus build preserves the existing browser labs and publishes the machine-readable catalogue at [`/catalog/labs.json`](/catalog/labs.json). Availability on this landing page is driven by each catalogue record's `status` field.
